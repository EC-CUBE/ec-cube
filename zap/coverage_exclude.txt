# zap/bin/coverage.sh で「シナリオが通らない」から外すルート。
# 1 行に 1 つ、ルートのパスに一致させる正規表現と、外す理由をタブで区切って書く。
# パスは bin/console debug:router の出力のとおりで、管理画面は ECCUBE_ADMIN_ROUTE (既定は admin) が展開されている。

# インストール後は使えない
^/install	インストーラ
# プラグインの検索・導入・有効化・削除は外部のストア API に依存し、処理のリソース消費が大きい
^/[^/]+/store/plugin	ストア・プラグイン管理
# ページ管理に表示するためのダミーのルートで、空の応答を返すだけ
^/product_review/display$	商品レビューのページ管理用のダミー
# 2 段階認証の設定・変更で付く cookie を ZAP が保持するため、認証済みになり表示されない (zap/scripts/totp.js)
^/[^/]+/two_factor_auth$	2 段階認証のログイン後の認証
