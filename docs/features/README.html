このページについて

利用者（購入者・店舗運営者・開発者）から見た EC-CUBE の機能を、機能 ID で一覧したものです。 結合試験項目書（EC-CUBE/eccube-specification）の観点表は、この機能 ID を参照して試験観点と手順を持ちます。 網羅性は、この一覧と観点表を機能 ID で突き合わせ、片方にしかない行を探して確認します。

  • 機能 ID — FR＝フロント（購入者）、AD＝管理画面（店舗運営者）、DV＝開発者・運用者（CLI・API・拡張）。AD-20-01 の中央の 2 桁がグループです（例: AD-20＝商品管理）。採番したら変えず、廃止した機能も欠番として残します。
  • 本体 PR — 機能を追加・変更した PR をリリースのバージョンごとに並べます。不具合修正だけの PR は載せません。
  • 導入バージョン — 4.4 より前からある機能は空欄です。
このページは docs/features/features.yaml から生成しています。機能を追加・変更する PR では features.yaml を更新し、 php .github/bin/feature-list.php でこのページを作り直してください。
